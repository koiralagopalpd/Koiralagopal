समूह बचत एप — FINAL
====================

प्रयोग:
1. samuha-bachat-app.html फाइल Chrome मा खोल्नुहोस्
2. पहिलो पटक: नयाँ खाता बनाउनुहोस् (Admin)
3. प्रोफाइल → अगाडिको हिसाब → नगद + कित्ता + ऋण + अग्रिम
4. मासिक असुली → महिना सुरु → कलेक्सन → कलेक्सन बन्द → ऋण → महिना बन्द

ब्याकअप:
  Export = JSON डाउनलोड + Google Drive खुल्छ
  Import = Drive/फाइलबाट JSON छानेर पुनर्स्थापना
